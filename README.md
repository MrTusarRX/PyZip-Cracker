## 📌 Overview  
**PyZip-Cracker** is a **brute-force ZIP password cracker** built for **Termux (Android)**.  
It automates **ZIP password cracking** using a **wordlist-based attack** with `pyzipper`.  

## ✨ Features  
✅ **Brute-Force Attack** – Cracks ZIP passwords using a wordlist  
✅ **Termux Support Only** – Designed for Android (Termux)  
✅ **Automatic Setup** – Installs Python and dependencies if missing  
✅ **Fast & Lightweight** – Uses `pyzipper` for efficient extraction
